So, Machine Learning is different from Rule-based systems (ex. Emails)
RBS uses data from emails and are given rules(Using code) to detect which of those emails are spam, then it gives an outcome
ML uses those outcomes and the data they are given to generate a model, the model is then given a set of data and then it gives an outcome
Using ML is more efficient as you don't need to change the rules or code of the system, they learn from the data they are given and use that knowledge to determine whether or not a specific email is spam or not.
